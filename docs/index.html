Estoque Solidario CLI

Aplicacao de linha de comando para organizar doacoes, distribuicoes e alertas de estoque em projetos sociais, agora com consulta de endereco por CEP usando a API publica ViaCEP.

Publicacao da etapa intermediaria

Esta pagina documenta a entrega publicada do projeto e aponta para o codigo-fonte, testes automatizados e fluxo de execucao da aplicacao CLI.

Repositorio: github.com/DanMarangon/Atividade-Bootcamp

$ py -m estoque_solidario

Controle de doacoes

Registra lotes com item, categoria, quantidade, validade e doador.

Relatorios de estoque

Mostra baixo estoque, lotes vencidos e itens proximos da validade.

Integracao ViaCEP

Consulta endereco por CEP via HTTP GET e exibe os dados no terminal.

Como executar localmente

Instale o projeto com as dependencias de desenvolvimento e rode o CLI.

py -m pip install -e .[dev]
py -m estoque_solidario

Validacao automatizada:

py -m pytest
py -m ruff check .
py -m ruff format --check .
